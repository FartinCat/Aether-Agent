# Skill: B04-plan-synthesizer (Multi-Plan & User-Idea Synthesis Engine)

**Objective**: Ingest competing plans, diverse agent strategies, and multi-faceted brainstorming ideas submitted by the user. Identify common ground (consensus), isolate conflicting decisions (clashes), and reconcile them into a single, cohesive, conflict-free **Golden Plan**. Prevent paralysis from analysis and eliminate contradiction between distinct ideas.

---

## 2. Core Operating Principles

1. **Dual Intake Flexibility (Agentic & Human)**:
   - **Agentic Proposals**: Reconciles competing proposals generated by different AI models, agents, or architectural variations from `B02-planner`.
   - **User Brainstorming Ideas**: Reconciles fragmented, diverse, or conflicting ideas submitted directly by the user (e.g. wishlist items, alternative tech stacks, conflicting UX preferences).

2. **The 3-Step Synthesis Protocol**:
   - **Step 1: Extract Baseline Consensus**: Identify non-controversial, shared requirements, files, and modules agreed across all inputs.
   - **Step 2: Isolate Clashes & Divergences**: Spot explicit contradictions (e.g., synchronous REST vs asynchronous message queues, relational table vs embedded document, third-party library vs custom implementation).
   - **Step 3: Execute Objective Resolution**: Resolve each clash by prioritizing simplicity, maintainability, low blast radius, and existing codebase conventions.

3. **Single Golden Plan Output**:
   - The end product must always be a **single, unified, unambiguous roadmap**.
   - No open forks or deferred contradictions. Every clash must have an explicit resolution rationale.

4. **The Independence Law**:
   - Zero raw absolute system paths (`d:\`, `file:///`, `C:\`). All file references must use clean relative paths (`src/...`).

## 4. Automated Synthesis Helper Script

`B04-plan-synthesizer` includes a self-contained reconciliation engine: `scripts/synthesize_plans.py`.

### How to Run:
```bash
python .agents/skills/B04-plan-synthesizer/scripts/synthesize_plans.py path/to/IDEAS_OR_PLANS.md
```

### Script Capabilities:
- Parses multi-section plans (`### Plan A:`, `### Idea 1:`, etc.).
- Maps all referenced files and detects file modification collisions.
- Highlights architectural contradictions (e.g., sync vs async execution models).
- Outputs structured consensus and clash reports in Markdown or JSON (`--json`).
